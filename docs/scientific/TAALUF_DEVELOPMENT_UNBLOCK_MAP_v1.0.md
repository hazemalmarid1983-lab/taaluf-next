## 3. ما يمكن تطويره دون قرارات علمية (استخراج من البنية فقط)

**مسموح (A) — دون افتراض fidelity/mastery/generalization/assessment equivalence/Canon assistance mapping:**

- تشغيل وصيانة **11** نشاطًا/media في الفصول الثلاثة عبر flows/engines الموجودة.
- **Plan Builder:** خطط لمعايير لها candidates (`C1`–`C3`, `C6`, `C8`, `C11`, `C15`, `C25`).
- **C15:** ضمن النطاق المنفّذ (S1–S3، `c15SkillMovementMap`، observer flow) — **بدون** Pass جديد و**بدون** S4/S5 executable.
- **Session engine:** validation، persistence، metrics **الحالية** (`accuracy`, `promptLevel`) — **L01/L02**.
- **UX/results:** نصوص disclaimer موجودة؛ presentation layers — **دون** ادعاء إتقان Canon.
- **Tests** على resolver، chapters، C15 integrity، plan builder — ضمن سلوك **LOCKED**.
- **Consultant / hub / home-classroom** كمسارات منفصلة عن «تدريب معيار» — ما لم يُربط goal progress بادعاء معيار.

**غير مستخرج من البنية (لا يُدرج كـ «يمكن الآن»):**

- C4 Activity / JSON / engine.
- حقول trial sequence (C4).
- مسار generalization/maintenance.
- كتابة assessment من training.
- تغيير +1/+2/+5 أو `masteryLevel` semantics ليعادل Canon.
